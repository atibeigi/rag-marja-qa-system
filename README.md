# rag-marja-qa-system

# سیستم پرسش و پاسخ مبتنی بر RAG برای استفتائات و رساله‌های مراجع تقلید

## معرفی

این پروژه یک سیستم پرسش و پاسخ (Question Answering) مبتنی بر معماری **Retrieval-Augmented Generation (RAG)** است که با استفاده از متون رساله‌های توضیح‌المسائل و استفتائات مراجع تقلید طراحی شده است.

هدف اصلی سیستم:
- پاسخ‌دهی به سوالات شرعی بر اساس نظرات مراجع مختلف
- بازیابی متون مرتبط و تولید پاسخ با استفاده از مدل زبانی


## قابلیت‌های اصلی

- قطعه‌بندی (Chunking) متون طولانی
- بازیابی اطلاعات با استفاده از **BM25**
- رتبه‌بندی مجدد نتایج با مدل **ParsBERT**
- تولید پاسخ با استفاده از مدل **Gemini**
- ثبت لاگ سوالات و پاسخ‌ها

## ساختار داده

دیتاست مورد استفاده شامل متون رساله توضیح‌المسائل و استفتائات چندین مرجع تقلید بوده است.  
ساختار کلی داده‌ها به صورت زیر است:

| ستون         | توضیحات                                      |
|--------------|-----------------------------------------------|
| `marja_name` | نام مرجع تقلید                               |
| `text_type`  | نوع متن (رساله / استفتاء)                    |
| `topic`      | موضوع متن                                    |
| `text`       | متن کامل                                     |

> **توجه:** به دلیل محدودیت‌های انتشار، دیتاست اصلی در این مخزن قرار داده نشده است.

## تکنولوژی‌های استفاده شده

- Python
- BM25 (`rank_bm25`)
- ParsBERT (`HooshvareLab/bert-fa-base-uncased`)
- Google Gemini (از طریق `langchain-google-genai`)
- Hazm (برای پردازش متن فارسی)
- Transformers + PyTorch
